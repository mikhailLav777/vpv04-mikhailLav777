# Контроль остатков для «Аппетитного Крыма»

## Что это

Учебная программа читает таблицу остатков товаров и показывает,
какие позиции пора пополнить и сколько единиц нужно добавить.
В примере используются вымышленные данные.

## Как запустить

1. Убедитесь, что установлен Python 3.12.
2. Откройте папку проекта в VS Code и запустите встроенный терминал.
3. В терминале выполните:

```powershell
py -3.12 main.py examples/stock.csv
```

Дополнительные библиотеки устанавливать не нужно.

## Как проверить, что работает

На таблице `examples/stock.csv` ожидается такой отчёт:

```text
ОТЧЁТ ПО ОСТАТКАМ
Позиций ниже минимума: 1
Товар                  Остаток  Минимум  Добавить
Корм для собак, 12 кг        2        5         3
```

Наполнитель с остатком 5 при минимуме 5 в отчёт не попадает.
Лакомства с остатком 8 при минимуме 4 тоже не попадают.

Одна и та же команда запускает тот файл, который находится
в текущей папке терминала.
